**VelociText** is a high-performance, lightweight web application designed to measure and improve Arabic touch-typing proficiency. It evaluates user typing performance in real-time, calculating Words Per Minute (WPM) and accuracy metrics under timed constraints.

🌐 **Live Preview:** [https://batool-dev1.github.io/typing-speed-ar/](https://batool-dev1.github.io/typing-speed-ar/)

---

## 🚀 Key Features

- **Real-Time Analytics:** Dynamic calculation of typing speed (WPM) and keystroke accuracy on the fly.
- **Arabic Language Optimized:** Curated Arabic text corpora tailored for natural touch-typing rhythm and linguistic accuracy.
- **Interactive Feedback:** Instant visual highlighting of correct and incorrect characters during active input.
- **Responsive UI/UX:** Clean, distraction-free interface optimized for various screen resolutions and desktop environments.

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3
- **Styling:** Custom CSS Flexbox/Grid architecture
- **Deployment & Hosting:** GitHub Pages
